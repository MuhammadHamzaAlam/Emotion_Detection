# Emotion Detection Application

This project implements an AI-based Emotion Detection web application using Watson NLP.

## Features

- Detects anger, disgust, fear, joy and sadness
- Determines the dominant emotion
- Flask web application
- Error handling
- Unit testing
### Testing

The project includes automated tests for the emotion detection functionality.

Run the test with:

```bash
python3.11 test_emotion_detection.py
```

Expected output:

```text
.
----------------------------------------------------------------------
Ran 1 test in 0.673s

OK
```

The `OK` indicates that all tests passed successfully.
